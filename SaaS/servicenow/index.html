ServiceNow 如何从 SaaS 的成功跨越 Agent 的挑战

20 篇素材 · 2026年8月9日
📌 核心观点
推 1 · 核心结论：为什么 ServiceNow 能跨越 Agent 挑战

① 什么变了：游戏规则从 系统记录 → 系统行动。AI Agent 让企业软件不再是人操作的按钮界面，而是自主执行工作的数字劳动力。SaaS 从「卖工具」转向「卖工作成果」，按席位定价正被按消费/结果定价取代。

② 战略：McDermott 押注 AI Control Tower + Autonomous Workforce + Action Fabric 三位一体。用22年积累的工作流数据壁垒防御 AI 原生颠覆者，以「Agent of Agents」开放平台抢先巩固治理中心地位——不锁定模型、不锁定云、连接一切。

③ 产品：真正壁垒不是模型而是 单一数据模型 + 工作流编排 + AI Control Tower 治理闭环。Agent 继承 ServiceNow 权限体系，不需要单独集成层——这是独立 AI 工具无法复制的架构优势。28.5亿美元收购 Moveworks 补齐前门体验。

④ 组织：McDermott 自我颠覆——内部 AI agent 解决90% IT 请求和89%客服请求，2025年节省1亿美元人力成本；50%净新业务已非按席位定价；282亿美元 RPO 增长26.5%证明转型可执行。3万人的饥饿谦逊文化是持久优势。

⑤ 一句话：工作流壁垒 × 治理优先 × 混合定价转型，三者缺一不可。ServiceNow 不是在等 SaaS 被颠覆，而是在用 Agent 重写 SaaS。

🏢 主题简介
推 2 · ServiceNow 公司介绍

ServiceNow（NYSE: NOW）由 Fred Luddy 于2004年创立，是全球领先的 AI 平台 for business transformation。

FY2025 总收入约 130亿美元，订阅收入128.83亿美元（+21% YoY）。Q4 订阅收入34.66亿美元（+21% YoY）。

RPO 282亿美元（+26.5% YoY），cRPO 128.5亿美元（+25% YoY）。603个客户超500万美元 ACV（+20% YoY）。

每年运行 750亿个工作流，服务85%的 Fortune 500。2025年12月完成5:1股票分割，2026年1月额外授权50亿美元回购。

推 3 · 创始人 Fred Luddy 与 CEO Bill McDermott

Fred Luddy 在50岁生日前两周从家里创办了 ServiceNow。他曾是 Peregrine Systems 的 CTO，离开后发誓不再做 ITSM——但「永远」的定义大约是9个月。

Luddy 的核心洞察：ITIL（IT 基础设施库）定义了 IT 流程标准，但没有人按此标准构建软件。他用 低代码+云原生+单一数据模型 架构，让 IT 工单管理变得像 Amazon 购物一样简单。

2019年 Bill McDermott 从 SAP 加入任 CEO。他将 ServiceNow 从 ITSM 扩展为「Platform of Platforms」——一个架构、一个数据模型，统一每个系统、工作流和体验。

面对 AI Agent 浪潮，McDermott 选择 自我颠覆：定位为「AI Control Tower for business reinvention」，50%净新业务转向非按席位定价。

推 4 · 典型客户：FedEx

FedEx 每天处理1800万件包裹，覆盖220+国家，50万员工。每月在 ServiceNow 上运行 500万个工作流，每天产生2PB数据。

FedEx CEO Raj Subramaniam：「商业和技术的区别正在消失。技术就是商业。」

FedEx 用 AI Control Tower 量化 AI ROI——95%的企业今天做不到这一点。他们是900亿美元全球物流运营的证明点。

📦 公司战略
推 5 · 定位：从 Platform of Platforms 到 Agent of Agents

ServiceNow 的定位演进：ITSM 平台 → 企业工作流平台 → AI Control Tower for business reinvention。

在 AI 时代，客户不想要锁定。ServiceNow 成为「AI Agent of Agents」——连接任何模型（OpenAI、Anthropic、Google Cloud、NVIDIA）、任何云、任何数据源。

McDermott 的核心论点：「智能正在成为商品。任何人都能获取前沿模型。差异化在于谁能在关键时刻应用智能，基于企业上下文，嵌入工作流。智能会越来越便宜。可信执行会越来越有价值。」

推 6 · 竞争格局：三强鼎立

Microsoft、Salesforce、ServiceNow 已成为企业 agentic AI 早期领导者。

Microsoft：最广泛的企业 AI 操作系统（Agent 365 + Azure AI Foundry + Copilot Studio + Entra ID），但面临运营复杂度风险。

Salesforce：最有野心但最不稳定，从 CRM 扩展到企业工作流编排，$2/对话消费定价。成功依赖企业运营准备度。

ServiceNow：在其领域内最成熟、最有生产验证。治理优先模型吸引风险意识强的企业。IT/HR 自动化有最清晰 ROI 故事。

核心判断：竞争正从模型质量转向 运营架构——编排、治理、互操作、工作流执行和信任。

推 7 · 护城河：22年工作流知识 + 治理闭环

ServiceNow 的结构性护城河是 单一架构 + 单一数据模型——22年映射企业如何工作：每条审批链、每条业务规则、每个升级路径、每个合规要求。

这些知识编码在每年运行 1000亿次的数千个工作流中，是部署能真正执行工作的 AI agent 的基础。

AI Control Tower 将护城河从「工作流执行」升级为「AI 治理」——不仅是 ServiceNow 的 agent，而是全企业所有 agent（包括 Claude、Copilot、自建 agent）的统一治理层。

Action Fabric 通过 MCP Server 向第三方 agent 开放 ServiceNow 全部行动能力——把竞争对手的 agent 变成 ServiceNow 治理的客户。

推 8 · 收购策略：Moveworks + Armis + Veza

Moveworks（28.5亿美元）：补齐 AI 原生前门——对话式 AI + 企业搜索 + Reasoning Engine。550万员工用户，250个共同客户。

Armis：资产可见性与安全态势管理，扩展到 IT/OT/IoT/医疗设备。安全市场机会扩大3倍以上。

Veza：AI 原生身份智能，映射人、机器和 AI agent 身份的权限——超300亿条权限记录。

三条收购20天内完成整合，对比企业软件收购常见的18个月重建周期。

🧩 产品战略

🔄 产品本身演进：会答 → 会协作 → 会做事 → 会决策

  • 会答：ITSM 工单 + Virtual Agent 基于规则单轮FAQ，22年积累工作流知识基座
  • 会协作：Now Assist GenAI 引入多轮对话+知识搜索+坐席增强，近1000个 AI 客户
  • 会做事：AI Agents 自主推理+工具调用+工作流执行，Zurich Release 嵌入 agentic AI 核心
  • 会决策：Otto 合并 Moveworks+Now Assist 端到端执行，AI Control Tower 五维治理+Kill Switch
推 9 · 产品演化路径

从 ITSM 工单管理 会答 → Now Assist 会协作 → AI Agents 会做事 → Otto + Autonomous Workforce 会决策。

20年从帮助台替代工具到企业 agentic 操作系统。Now Assist 是公司历史上增长最快的产品——从0到6亿美元 ACV 仅约2年。

关键转折：2024年9月发布 AI Agents，从 prompt-based 活动转向 deep contextual comprehension——agent 自主运行、检索数据、构建行动计划并无人工干预执行。

推 10 · AI Control Tower：五维治理架构

AI Control Tower 是 ServiceNow 的 治理护城河——从可见性工具升级为企业 AI 指挥中枢。

五维：Discover（自动发现全企业 AI 资产）→ Govern（策略/权限/护栏）→ Observe（实时监控 agent 行为）→ Secure（AI agent 身份治理）→ Measure（业务价值量化）。

30+企业集成覆盖 AWS、Google Cloud、Azure、SAP、Oracle。KN26 演示：prompt injection 攻击的 agent 被实时检测、撤销权限、数秒内 kill switch 关闭。

95%的企业今天无法度量 AI ROI——AI Control Tower 让这变得可度量。

推 11 · 产品架构四层

① Now Platform 数据层：单一数据模型 + Workflow Data Fabric，22年企业上下文沉淀

② AI Control Tower 治理层：Discover + Govern + Observe + Secure + Measure，覆盖原生和第三方 agent

③ Autonomous Workforce 执行层：AI 专家覆盖 IT/CRM/员工服务/安全，端到端工作执行

④ Otto + Action Fabric 交互层：合并 Moveworks+Now Assist 的 AI 前门 + MCP Server 向第三方 agent 开放

四层融合是独立 AI 工具无法不开多年代集成项目就复制的。

推 12 · 定价模式转型

从 按席位收费 到 混合模式：2026年4月用三个 AI 原生层级（Foundation/Advanced/Prime）替代五个遗留包。

AI 不再是可选附加——捆绑在每个层级中，按 Assists 消费单位 计量。轻量操作（摘要）消耗远少于多步 agentic 工作流。

McDermott 的 Goldilocks formula：不太热（纯按席位），不太冷（纯按消费），刚好——混合模式。50%净新业务已非按席位定价。

续约率仍保持97%——证明转型可执行，不致命于现有收入基座。

🏗️ 组织文化
推 13 · 组织演化：自我颠覆

ServiceNow 内部 AI agent 自主解决 90%的 IT 请求 和 89%的客户支持请求，解决时间缩短近7倍。

L1 服务台 AI 专家解决分配 IT 案例速度比人工快 99%。2025年内部 AI 效率节省约 1亿美元 人力成本。

McDermott 预测：净新增员工数成长将大幅减少——不是通过裁员，而是 agent 吸收原本需要新雇数千人的工作量。投资转向工程师和高信任客户关系人员。

到2030年全球5000万劳动力短缺，同时数十亿 AI agent 上线——「工作的世界正在被重塑。」

推 14 · GTM：生态合作驱动

与所有三大超大规模云厂商合作：AWS、Google Cloud、Microsoft Azure。

与所有主要 LLM 厂商集成：OpenAI（前沿模型能力）、Anthropic（Claude 深度集成+Code）、NVIDIA（Project Arc + OpenShell 信任层）。

91%的净新 ACV 来自涉及5个以上产品的交易——多产品交叉销售是增长引擎。

Now Assist 交易中包含3个以上产品的增长近70% YoY。244笔超100万美元交易（+40% YoY）。

推 15 · 客户案例与结果

FedEx：每月500万工作流，AI Control Tower 量化 AI ROI，2PB/天数据驱动供应链优化。CDIO Talwar 三铁律：工作流澄清→数据洁净度→AI 素养培育。

Honeywell：AI 助手「Red」消除大部分服务台对话，企业规模运营 AI 劳动力。

ServiceNow 自身：Autonomous CRM 每月解决1亿+客户案例、编排1600万订单、配置700万报价。Otto 上线一个月生成6笔超100万美元 ACV 交易。

Autonomous Workforce 客户案例 91%无需重新分配即解决。每月2300万员工使用员工门户，年4000万案例。

推 16 · 文化与管理：饥饿且谦逊

McDermott：「我们30,000人每天醒来聚焦一件事：将客户最大挑战转化为更大机遇。饥饿且谦逊的文化是我们的持久优势。」

100天上线保证+完全满意度保证——企业软件公司首次。「你不必想象 agentic business 是什么样。你实际上就在一个里面。」25,000名参会者的每个事件和服务请求被感知、路由和解决。

免费 AI Control Tower 是 land。Action Fabric 是 expand。Autonomous Workforce 是 lock-in。

Jensen Huang 给企业领导者的建议：「提升你的雄心。思考比生产力增益更大的东西。」
