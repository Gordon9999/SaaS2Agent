附录 07 · NVIDIA OpenShell + Project Arc

📌 核心观点
推 1 · 信任层架构

NVIDIA OpenShell 与 ServiceNow AI Control Tower 的组合，正在构建自主 AI agent 的信任层——让企业不仅能部署 agent，更能可审计地控制其每一个行动。

核心转变：从"部署 agent 并希望它表现好"到"部署 agent 并可审计地控制其每个行动"。

推 2 · 安全+治理

双层信任架构清晰分工：NVIDIA OpenShell 负责运行时安全沙盒，ServiceNow AI Control Tower 负责企业级治理与策略控制。

这种安全+治理的双层设计意味着 CISO 可以首次自信地审计和批准自主 AI——不是基于希望对 agent 行为的猜测，而是基于可观测可治理的证据。

👤 访谈人背景
推 3 · 来源背景

本文来自 ServiceNow Community 技术社区，发布于 2026 年 5 月，是 ServiceNow 对 NVIDIA Computex 发布 OpenShell 后的官方技术解读。

素材定位为技术集成公告，面向开发者与架构师群体，涉及运行时安全与治理的深层技术设计。

💬 行业
推 4 · 自主 agent 新范式

新一代企业 AI agent 的行为模式发生了质变：推理、写代码、执行、循环直到做对——不回答问题就停，而是承担复杂多步工作、适应意外情况、自主运行数小时。

这种 agent 对安全的要求远超传统 chatbot——每个文件读取、命令执行、网络调用都需要被治理。

推 5 · 行业信号

NVIDIA 选择在 Computex 发布 OpenShell，并与 ServiceNow 深度集成，释放了明确信号：自主 agent 的基础设施层正在形成。

GPU 厂商做安全运行时、工作流厂商做治理层——生态分工逐渐清晰，基础设施标准化将加速 agent 在企业中的采纳。

📦 公司
推 6 · 信任为核心

ServiceNow 通过 Project Arc 证明其在自主 agent 领域的策略：从零构建，信任层为核心。

不是给现有产品加 agent 功能，而是以安全可审计为前提重新设计 agent 架构，这体现了治理优先的 DNA。

推 7 · Project Arc

Project Arc 是 ServiceNow 的可信任自主 agent 项目，核心能力包括：通过 Action Fabric 拥有平台全部力量，每个关键行动在 OpenShell 中运行，每个行动由 AI Control Tower 治理。

策略集中设置，行为持续监控，每个文件读取、命令执行和 API 调用被完整记录。

推 8 · 生态伙伴选择

ServiceNow 选择 NVIDIA 作为运行时安全伙伴而非自建沙盒，说明公司策略是聚焦治理层，与基础设施合作伙伴分工。

这种务实的生态合作策略有助于加速产品上市，同时保持治理优势。

🧩 产品
推 9 · OpenShell 机制

NVIDIA OpenShell 提供安全沙盒运行时：agent 从零权限开始，每个资源必须显式授权。

每个文件读取、命令执行、网络调用都经过 OpenShell，实现了最小权限的强制执行——agent 不会获得任何未授权的系统访问能力。

推 10 · AI Control Tower 治理

ServiceNow AI Control Tower 提供三层治理能力：发现企业中每个活跃自主 agent，定义角色感知策略，观察 LLM 调用和工具调用，提供kill switch。

从发现到监控到紧急切断，形成完整的治理闭环。

推 11 · 行动记录

每个关键行动的完整审计链路：策略集中设置 → 行为持续监控 → 每个文件读取、命令执行和 API 调用被记录。

这种全链路可观测性让安全团队第一次拥有了对自主 agent 的完整审计能力。

🏗️ 组织
推 12 · CISO 视角

整个架构设计围绕 CISO 的审批需求展开："CISO 可以自信地审计和批准自主 AI，不是因为他们希望它表现好，而是因为他们能看到、治理和安全其采取的每个行动"。

从安全团队的视角出发设计产品，是 ServiceNow 在治理赛道建立信任的关键策略。

推 13 · 企业采纳门槛

自主 agent 在企业中大规模部署的最大障碍不是能力，而是信任与合规。

OpenShell + AI Control Tower 的组合直接针对这一门槛——让安全审批从一个信念问题变成一个审计问题。

推 14 · 零权限起点

OpenShell 的核心设计哲学极具安全性：agent 从零权限开始运行，每个系统资源必须显式授权。

这颠覆了传统应用安全模型——不是先授权再限制，而是默认拒绝一切，只开放必要的权限。

推 15 · 行业意义

NVIDIA + ServiceNow 的信任层组合代表了硬件安全能力与软件治理能力的首次深度耦合，专为自主 agent 场景设计。

这可能成为企业自主 AI 部署的标准参考架构，后续会有更多运行时和治理平台跟进类似模式。

推 16 · 总结

OpenShell + Project Arc 不只是一次技术集成，而是定义了可信任自主 agent 的架构蓝图。

运行时安全沙盒 + 企业治理平面 + 全链路审计 = 让自主 AI 从技术 demo 走向企业生产环境。
