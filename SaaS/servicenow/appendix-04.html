附录 04 · ITSM AI Agents：从 Virtual Agent 到 Agentic AI

来源：ServiceNow Community · ITSM AI Agents 博文
📌 核心观点
推 1 · 2025年是 AI Agent 元年

2025年被定义为 AI Agent 元年。AI Agent 代表了超越传统 ML、Virtual Agent 和 GenAI 的变革性飞跃——不只是更聪明的对话，而是能自主推理并采取行动。

推 2 · SaaS 的下一参与层

SaaS 的基本角色是为知识工作者提供 UI 和数据库以简化工作流。AI 演进后，15-20% 的知识工作者任务将由 AI Agent 处理。AI Agent 正成为企业的下一参与层和逻辑层。

👤 访谈人背景
推 3 · 来源信息

来源类型：ServiceNow Community 官方博文，ITSM AI Agents 主题。发布时间未提供，访谈人未提供，嘉宾未提供。时长未提供。属于官方产品技术推广类内容。

💬 行业
推 4 · 从 ML 到 GenAI 到 Agentic AI

AI 在企业中的演化路径：传统 ML（预测）→ Virtual Agent（规则对话）→ GenAI（生成内容）→ Agentic AI（自主推理+行动）。每一步都在扩大 AI 的自主性和行动范围。

推 5 · 15-20% 任务将被 Agent 接管

15-20% 的知识工作者任务将由 AI Agent 处理。这不是替代，而是重新分配——人聚焦判断和创意，agent 负责执行和协调。行业正在重新定义"工作"的组成。

推 6 · 消除刚性决策树

传统自动化依赖刚性决策树，部署门槛高、维护成本大。AI Agent 用 LLM 驱动的自主推理替代决策树，显著降低部署门槛——这是 agent 能大规模落地的关键。

📦 公司
推 7 · 工作流、系统记录和领域上下文的所有权

ServiceNow ITSM AI Agents 独特性的根基：对工作流、系统记录和领域上下文的所有权。这不是外挂 AI，而是原生在平台数据和工作流之上的 agent。

推 8 · 继承平台安全性

ITSM AI Agents 直接继承 ServiceNow 平台的安全性和数据定义，不需要单独集成层。这意味着 agent 从第一天起就具备企业级安全合规——这是竞品难以复制的优势。

推 9 · 利用既有业务逻辑

AI Agent 可以直接利用 ServiceNow 已有的业务逻辑：审批、分类、路由、优先级、升级。22年积累的 ITSM 最佳实践成为 agent 的"企业常识"，而非从零学习。

🧩 产品
推 10 · 核心能力：自主推理+行动

AI Agent 的核心能力由 LLM 驱动，能做决策、采取行动、与环境交互，无需持续人工干预。这是与 Virtual Agent 的根本区别——后者只能按预设路径对话，前者能自主完成端到端任务。

推 11 · 直接访问实例数据

ITSM AI Agents 直接访问实例数据，可调用集成、流程、脚本和工具。不需要额外 API 或中间层，agent 就在数据源头工作。这大幅降低了延迟和出错概率。

推 12 · 多 agent 架构

不同于单 agent 方法，ServiceNow 采用 多 agent 架构：多个专家 agent 由编排器管理，以质量换延迟。单个 agent 专门化于特定领域，协同完成复杂任务。

推 13 · 端到端事件生命周期

ITSM AI Agent 覆盖从偏转到分类、解决和关闭的整个事件生命周期。可手动触发或自主运行，可定义哪些行动需要人工在环确认。自主与可控并行。

推 14 · 未来：Observability 与自动化测试

未来能力包括 AI Agent Observability（监控 agent 性能和影响）以及自动化测试和验证工具。agent 不是部署完就结束——持续的监控和验证是企业级 AI 的必要条件。

🏗️ 组织
推 15 · 开箱即用的领域特定 agent

ServiceNow 提供的是 开箱即用的领域特定 agent，而非通用 AI 框架。这意味着企业不需要从零构建——基于 ITSM 最佳实践预配置的 agent 可以快速部署、快速见效。

推 16 · 人工在环的可控设计

agentic AI 不是完全自治。ServiceNow 的设计允许企业定义哪些行动需要人工在环确认——在高风险操作上保留人类决策权，在低风险操作上释放 agent 自主性。这是企业能接受 agent 的组织前提。

推 17 · 从 ITSM 出发的 agent 扩张

ITSM 是 ServiceNow agent 战略的起点，但不是终点。从 IT 服务台出发，agent 能力将向案例管理、安全、财务、HR、法律等全职能扩展。ITSM 是验证场，全企业是终局。
