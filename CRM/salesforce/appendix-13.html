📌 核心观点
推 1 · 统一架构

所有 Agentforce 解决方案都组合同一组组件：

Atlas(大脑) + Trust Layer(护栏) + Agent Builder(配置) + Prompt Builder(提示) + Data Cloud(grounding) + Salesforce平台(行动)

预构建 agent 和自定义 agent 用的是同一套组件的不同配置。

🧩 产品
推 2 · 多模型星座

Atlas 不是 单一 LLM，而是 专门化小语言模型星座。

意图分类、规划、grounding、行动选择各用不同的小模型。

这意味着不同子任务用最优化的模型，而非一个大模型做所有事。

推 3 · Trust Layer 机制

Trust Layer 在 prompt 到达外部模型前 mask PII。

扫描输出中的 毒性、提示注入、grounding 违规。

执行与模型提供商的零数据保留协议。记录每个操作供审计。

推 4 · Agent Builder

Agent Builder 是配置面：定义 topics（专业化范围）、actions（能做什么）、instructions（行为方式）。

预构建 agents 是这些组件的预配置组合。

自定义 agents 是同一组件的自定义配置——不是不同的平台。

推 5 · 混合推理

Agent Script 引入 引导确定性模型(guided determinism)。

定义固定交接规则，LLM 处理中间推理。

Salesforce 承认 完全自主多智能体编排尚未企业就绪。

这是确定性护栏内概率智能的混合架构。

推 6 · 架构师现实

架构评审中6个人有6种 Agentforce 心智模型。

架构师需在两周内给出建议：自建 agent、用预构建 agent、扩展预构建 agent、还是等下一版。

关键认知：Agentforce 不是"添加到 Salesforce 的 AI 功能"，而是运行在 Salesforce 之上的平台。
