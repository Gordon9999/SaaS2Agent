推 3 · 发生了什么变化

Grok Bot 把这个矛盾推到极限——它要的不是授权，是登录凭证本身。

推 7 · 无 API 是整个赌注

过去十年企业自动化卖的都是集成目录：你的工具在列表里就有自动化，不在就等 roadmap。

Grok Bot 的 computer use 绕开厂商准入权——不需要 API、不需要 MCP、不需要合作协议。

代价：慢、脆（改版就断）、难审计。xAI 文档自己也建议「有 connector 就优先 connector」。

推 13 · 三种凭证范式

Grok Bot：给凭证就用，2FA 人工交接，不进对话记录。

ChatGPT Work：代管登录和安全码，模型本身看不到凭证。

Claude Cowork：named connectors，写操作默认人工确认。

三家信任哲学，全在「钥匙怎么给」这一件事上。

推 16 · 信任前科加压
