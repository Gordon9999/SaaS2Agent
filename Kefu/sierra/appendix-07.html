附录 07 · Sierra Agent OS 2.0：从答案到记忆与行动

8 个新产品，三条演进主线（官网发布文）
InsightView · AI 客服之 Sierra · 2026-08-07
📌 核心观点
推 1 · 核心观点

这是 Sierra 产品演进的最佳单篇资料：Sierra Summit 一口气发布 8 个新产品，用三条主线勾勒方向——多渠道 → 单一 Agent、技术 → 产品、对话 → 关系。

产品从「提供答案」走向「记忆与行动」——对话正在成为界面，Agent 需要记忆和上下文去建立持久客户关系。

👤 访谈人背景
推 2 · 发布信息

发布时间：2025-11-05（Sierra Summit 首届客户大会）。作者：Bret Taylor、Clay Bavor。类型：官方产品发布文（非访谈）。

💬 行业
推 3 · 单一 agent 世界

客户体验正从多渠道走向单一 agent 世界：今天大多数公司仍为呼叫中心、网站、App 设置独立团队和独立体验，但 AI 能全部处理——现在 agent 还能接电话了。

推 4 · 对话成为界面

AI 助手是互联网的前门，就像过去 25 年搜索一样——ChatGPT 周活超 8 亿，是史上增长最快的产品，很快每个人都会有自己的个人 agent。

推 5 · agent 构建的 1997 时代

当年公司花数千万美元只是为了上线网站；今天的「无代码」工具能快速到一垒但处理不了企业级复杂用例——商业价值恰恰在复杂的订阅流失管理、受监管工作流、多步骤销售流程里。

📦 公司
推 6 · 构建一次部署到任何地方

构建一次，部署到任何地方——chat、voice、email、SMS，以及两个新地方：ChatGPT 和你的呼叫中心。

推 7 · agent 是客户交互的起点

在单一 agent 世界里，公司的 AI agent 是每次客户交互的起点——从产品发现、推荐到销售、注册、排障、忠诚度、留存，还会协助服务与销售坐席。

推 8 · 像 Shopify 之于电商

Agent OS 产品化 agent 构建过程——让每个人（不只是工程师）都能成为 AI 架构师，构建有真正 agency 的工业级 agent，而不是披着 agent 外衣的标准操作流程。

🧩 产品
推 9 · Agent Studio 2.0

Journeys 让每个团队获得开发者同等的控制力（自然语言定义目标和护栏）；Workspaces 带来 GitHub 式跨 CX、运营、工程协作；Integrations 几分钟连接系统。

推 10 · Insights 2.0

Explorer 能即时分析海量交互诊断问题；Expert Answers 把呼叫中心专业知识变成有根据的文章，自动增强 agent 表现——用 AI 持续改进 AI。

推 11 · Publish to ChatGPT

一键把 agent 发布到 ChatGPT，支持交互式地图、可填表单、详细图表——不需要在分发与去中介之间做选择，完全控制哪些旅程、数据、能力出现在 ChatGPT。

推 12 · Live Assist

把 AI agent 超能力带入每次客户交互：实时指导支持团队、自动捕获细节、即时答案、推荐下一步。不是每段对话都该由 AI 处理，有时需要人情味。

推 13 · Agent Data Platform

ADP 是 Agent OS 的记忆与智能层：统一每次对话（非结构化）与结构化数据（客户、计费、库存、政策、交易）。

有了统一视图，agent 获得真正 agency：跨时间连接点、预判需求、主动代表客户行动——甚至在问题发生前解决它。

🏗️ 组织
推 14 · 组织协作模式改变

Workspaces 让 CX、运营、工程团队以 GitHub 式协作构建 agent——agent 构建不再是工程师的专属领地。

推 15 · 人机协作的设计

「不是每段对话都该由 AI 处理」——Live Assist 的定位反映产品对人机协作的设计：AI 增强人类坐席，而非完全替代。

推 16 · 用 AI 持续改进 AI

「它给 agent 从交易走向关系、从被动走向主动所需的记忆和上下文，它用 AI 持续改进 AI」——这是 Agent OS 的闭环设计。
